# Assets

- `disordered_DMS_substitutions_ref_file.csv`: DMS substitutions reference file from [ProteinGym](https://github.com/OATML-Markslab/ProteinGym).
- `DisProt_release_2024_12_consensus_regions.tsv`: DisProt data from 2024/12 release with consensus data downloaded from `https://disprot.org/download`.
- `DisProt_release_2024_12.tsv`: DisProt data from 2024/12 release with consensus data downloaded from `https://disprot.org/download`.
- `entry_name_to_uniprot_id_map.csv`: csv file that maps IDs used for each protein in ProteinGym to the appropriate UniProt IDs in the DisProt database.
- `uniprot_idmapping_2024_09_13.tsv`: UniProt ID mapping web tool output for the ProteinGym UniProt IDs. Converted PSAE_SYNP2 to PSAE_PICP2 before mapping. Available under the CC BY 4.0 [license](https://www.uniprot.org/help/license).
- `DMS_substitutions_Spearman_DMS_level.csv` File from [ProteinGym](https://github.com/OATML-Markslab/ProteinGym) containing model spearman correlation scores averaged at the DMS level.
- `DMS_substitutions_Top_recall_DMS_level.csv` File from [ProteinGym](https://github.com/OATML-Markslab/ProteinGym) containing model Top recall scores averaged at the DMS level.
- `disordered_DMS_substitutions_ref_file.csv` Reference with disordered regions. This file was created by combining the ProteinGym reference file with the disordered regions in each protein's target sequences.
